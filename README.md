# Personal Expense Tracker System

A dynamic, responsive, and secure web-based application designed to help users record, manage, and analyze their daily finances efficiently. Built as an individual web programming coursework assignment (CoSc3091).

## ✨ Features
* **User Authentication:** Secure registration and login system with password hashing (`password_hash()`) and session handling.
* **Dashboard Overview:** Displays total income, total expenses, and current remaining balance.
* **Expense Management (CRUD):** Add, view, edit, and delete daily transactions with categories and dates.
* **Contact & Feedback System:** Working contact form allowing users to send messages directly to the system.
* **About Page:** System details alongside developer bio and academic background.

---

## 🛠️ Tech Stack & Prerequisites
* **Frontend:** HTML5 (Semantic elements), CSS3 (Responsive layout), JavaScript (Form validation & DOM interaction)
* **Backend:** PHP (PDO database connection with prepared statements)
* **Database:** MySQL / MariaDB
* **Local Server:** XAMPP / WAMP / MAMP
